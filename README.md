# ЭДО Мост для Safari

Небольшое приложение для macOS, которое позволяет подписывать документы электронной подписью (ЭЦП) в сервисе **Моё Дело (ЭДО)** через браузер **Safari**.

> ⚠️ **Неофициальный проект.** Не связан с компанией «Моё Дело» и её правообладателями. Все товарные знаки принадлежат их владельцам.

## Зачем это нужно

Плагин ЭЦП «Моё Дело» (на базе КриптоПро) поднимает локальный сервер на `http://127.0.0.1:18080` и работает в Chromium-браузерах (Chrome, Edge, Яндекс). **Safari** блокирует обращение защищённой `https`-страницы к локальному `http://127.0.0.1` как «mixed content» — поэтому в Safari появляется «Не найден плагин».

Это расширение — тонкая прослойка: оно перехватывает обращения страницы к локальному плагину и выполняет их **из контекста расширения**, где запрет mixed content не действует. Сам плагин и КриптоПро остаются прежними — их менять не нужно.

## 🔒 Безопасность и приватность

Проект открыт именно для проверки. Что важно знать:

- **Никакой телеметрии и внешних серверов.** Расширение ничего не отправляет «наружу». Единственные сетевые запросы идут на `http://127.0.0.1:18080` — локальный плагин на вашем же компьютере.
- **Минимум разрешений.** В манифесте указаны только `127.0.0.1`, `localhost` и `moedelo.org`. Доступа к другим сайтам нет.
- **Ничего не хранит.** Сертификаты и подписи проходят «насквозь» между страницей и плагином и нигде не сохраняются.
- **Нет скрытого нативного кода.** Единственный сетевой вызов — в [`extension/background.js`](extension/background.js), в открытом виде. Нативная часть (Swift) — это окно-инструкция «как включить расширение», сетевых операций она не выполняет.
- **Крошечный объём.** Вся логика — три коротких файла (см. ниже), их реально прочитать за пять минут.
- **Подписано и нотаризовано Apple.** Релизный `.dmg` подписан сертификатом Developer ID и проверен сервисом нотаризации Apple.

## Где смотреть код

| Файл | Что делает |
|---|---|
| [`extension/manifest.json`](extension/manifest.json) | Разрешения и список разрешённых сайтов |
| [`extension/inject.js`](extension/inject.js) | На странице подменяет `fetch`/`XMLHttpRequest` и ловит обращения к `127.0.0.1` |
| [`extension/content.js`](extension/content.js) | Передаёт запросы между страницей и фоновым скриптом |
| [`extension/background.js`](extension/background.js) | **Единственное место сетевого вызова** — к локальному плагину |
| `xcode/.../SafariWebExtensionHandler.swift` | Нативная заглушка (без сети) |
| `xcode/.../ViewController.swift` | Окно-инструкция «включите расширение» |

## Как это работает

1. На странице `moedelo.org` скрипт `inject.js` подменяет `fetch`/`XHR` и перехватывает обращения к `http://127.0.0.1:18080/...`.
2. `content.js` передаёт их фоновому скрипту расширения.
3. `background.js` выполняет запрос к локальному плагину (в контексте расширения mixed content не блокируется) и возвращает ответ обратно странице.

Для страницы всё прозрачно — она «видит» плагин и подписывает документ как обычно.

## Сборка из исходников

Нужны macOS и Xcode.

```bash
git clone https://github.com/PavelDemyanov/edomost-safari.git
cd edomost-safari
open xcode/MoeDeloBridge/MoeDeloBridge.xcodeproj
```

В Xcode выберите свою команду в **Signing & Capabilities** и запустите (⌘R) — расширение появится в настройках Safari. Сборку релизного нотаризованного `.dmg` делает скрипт [`release.sh`](release.sh) (нужны сертификат Developer ID и профиль нотаризации).

## Требования

- macOS 12 (Monterey) или новее, браузер Safari
- Установленные **КриптоПро CSP** и **плагин «Моё Дело»** (тот же, что используется в Chrome)
