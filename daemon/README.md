# trustd — служба подписи «ЭДО Мост для Safari»

Нативный (Apple Silicon, arm64) HTTP-демон, который позволяет подписывать документы
в «Моё Дело» из Safari. Он встраивается в приложение «ЭДО Мост для Safari»
(`Contents/Helpers/trustd`) и слушает `http://127.0.0.1:18080`.

## Что он делает

Браузерное расширение «ЭДО Мост» пересылает демону запросы страницы moedelo.org,
а демон выполняет их через **CryptoAPI КриптоПро CSP** — ту самую криптографию,
которая уже установлена у вас для Chrome/Яндекс.Браузера. По сути это тонкая
обёртка: принять HTTP-запрос → вызвать КриптоПро → вернуть результат.

Реализованный протокол `/TRUST/*` описан в [PROTOCOL.md](PROTOCOL.md).
Ключевой метод — `GETSIGN_SYNC`: открепленная подпись **CAdES-BES, ГОСТ Р 34.10-2012**.

## Зачем он нужен

Прежний плагин подписи «Моё Дело» (StekTrust) — приложение только для процессоров
Intel и работает через Rosetta 2, поддержка которой в macOS сворачивается. `trustd` —
нативная замена под Apple Silicon: тот же протокол, та же криптография КриптоПро,
но без Rosetta. Отдельный плагин «Моё Дело» с ним больше не нужен.

## Приватность

Демон слушает только локальный адрес `127.0.0.1` (петлю) — наружу ничего не ходит.
Закрытый ключ никогда не покидает ваш токен/КриптоПро: PIN запрашивает сам КриптоПро,
подпись считается его средствами. Исходник открыт именно для того, чтобы в этом можно
было убедиться.

## Сборка

Требуется установленный **КриптоПро CSP** (даёт заголовки в `/opt/cprocsp/include`
и фреймворк `/Library/Frameworks/CPROCSP.framework`).

```sh
./build.sh trustd        # → arm64-бинарь trustd
./trustd                 # слушает 127.0.0.1:18080 (или ./trustd <порт>)
```

Флаги линковки: `-framework CPROCSP -lcapi10 -lrdrsup -flat_namespace`
(CPROCSP = libcapi20; базовые функции CSP — в libcapi10; `GetLastError` — в librdrsup).

Встраивание в .app и подпись — `embed_trustd.sh <path-to-.app> [signing-identity]`
(hardened runtime + `trustd.entitlements`).

## Файлы

| Файл | Назначение |
|---|---|
| `trustd.cpp` | сам демон (все 7 методов `/TRUST/*`) |
| `build.sh` | компиляция под arm64 |
| `embed_trustd.sh` | встраивание + подпись в бандл приложения |
| `trustd.entitlements` | entitlements демона (disable-library-validation для либ КриптоПро) |
| `PROTOCOL.md` | описание протокола `/TRUST/*` |

Референс-примеры использования CryptoAPI КриптоПро — в комплекте CSP:
`/opt/cprocsp/src/samples/CSP/` (в частности `CryptMsgSign`).
